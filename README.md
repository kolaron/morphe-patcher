# Morphe Patches

[![Release](https://github.com/kolaron/morphe-patcher/actions/workflows/release.yml/badge.svg?branch=main)](https://github.com/kolaron/morphe-patcher/actions/workflows/release.yml)

A small, curated set of Morphe patches.

This repository currently contains a single patch for **IDOS**, focused on improving the app experience by removing ads.

## Goals

Only patches that fit the purpose of making the app experience cleaner and less distracting are included.

## Notes

- Patch support may depend on the target app version.
- More patches may be added over time.
- This repository is intentionally kept small and focused.

## Disclaimer

This project is provided for educational and research purposes only. Use patches only on apps you are allowed to modify, and make sure you comply with the app's terms and applicable law.
